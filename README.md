# NASQ for Salla

NASQ is a standalone Twilight theme written from scratch. It does not inherit templates or styles from Theme Raed.

## Foundation

- Three header layouts with independent controls and custom logo support.
- Three footer layouts with custom logo and visibility controls.
- Home-page components for a hero, feature strip, and banner grid.
- Dependency-free asset build and structural validation.

## Commands

```bash
npm run production
```
