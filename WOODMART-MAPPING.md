# NASQ feature map

NASQ adopts the discoverability and breadth of a mature multipurpose commerce theme while remaining native to Salla Twilight. It does not copy WoodMart code, assets, UI, or branding.

## Native theme scope

| Familiar commerce capability | NASQ / Salla implementation |
| --- | --- |
| Global theme panel | Grouped `twilight.json` settings with Arabic and English labels |
| Prebuilt demos | Component presets and documented section recipes |
| Header layouts | Header presets, sticky mode, mega menu, search and mobile controls |
| Product-card styles | Editorial, minimal and compact presets |
| Product grids/carousels | Native Salla product sources with responsive column presets |
| Variation swatches | Native `salla-product-options` color, thumbnail and size controls |
| Quick view / quick add | Native Salla product-card and cart interactions |
| Product gallery/video | Native Salla gallery, video and option-linked thumbnails |
| Sticky add to cart | Native Twilight setting, enabled by default |
| Size guide | Native Salla product size guide |
| Wishlist | Native Salla wishlist components |
| AJAX search | Native `salla-search` component |
| Filters/off-canvas filters | Native Salla product-list filters and responsive drawer |
| Brands | Native brands pages and home component |
| Recently viewed | Client-side local history component (planned) |
| Shop the look | NASQ fashion component |
| Occasion collections | NASQ fashion component |
| Typography/colors/spacing | Theme settings and CSS custom properties |
| Performance controls | Lazy images, deferred interactions, content visibility and reduced-motion support |

## Requires a separate Salla app or platform support

These features cannot be reliably delivered by a storefront theme alone because they require persistent merchant data, admin workflows, checkout changes, or server-side catalog queries.

| Capability | Required solution |
| --- | --- |
| Product comparison with saved tables | Salla app |
| Dynamic frequently-bought-together rules and bundle discounts | Salla app or native bundle configuration |
| Behavior-targeted popup builder | Salla app; basic visual popup can be theme-only |
| Back-in-stock workflow | Native Salla availability notification |
| Advanced review voting and review criteria | Salla app |
| Price-drop tracker | Salla app |
| Server-side out-of-stock sorting override | Platform query support or Salla app |
| Custom checkout layout | Restricted to Salla checkout capabilities |
| Conditional layout builder per taxonomy | Multiple theme presets where supported; full parity needs platform support |
| Email marketing automation | Salla app/integration |
